# Rhino sprite — work in progress

Source image: `~/Downloads/Gemini_Generated_Image_saoxmlsaoxmlsaox.png`
Converted: 33×35px XBM-packed (bw=5 bytes/row, LSB-first, bit=1=black)
to replace the dino in `screen_game.cpp`'s `dino_bits[3][200]`.

## How to restore

In `screen_game.cpp`, replace the three `{ ... }` lines of `dino_bits`
with the three frames below. The comment block above the array should also
be updated to describe the rhino.

## Current state / next steps

- 3 synthetic animation frames: body identical across all 3, legs (rows
  27-34) shifted -2/0/+2 px horizontally for a simple trot cycle.
- Works, renders recognisably. Needs refinement: ideally a second source
  reference pose (legs in opposite stride) to create a true 2-frame walk
  cycle rather than this horizontal-shift approximation.
- The conversion script lives in PLAN.md's Day 5 "Image asset conversion"
  note — recreate from there if needed.
