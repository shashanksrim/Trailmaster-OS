Your browser can’t flash over USB. Use Chrome or Edge on a desktop. USB access was blocked. This page must be served over HTTPS.
How to flash:
1. Plug the device into this computer with a USB cable.
2. Click Flash via USB above.
3. In the popup, pick the port named like usbmodem… (or USB JTAG/serial).
4. Wait for it to finish, then the device reboots into the new firmware.
Chrome or Edge on desktop only. Web USB flashing isn’t supported in Safari, Firefox, or on phones. Saved Wi-Fi networks are preserved (no full erase).
