Your browser can't flash over USB — use Chrome or Edge on a desktop. USB access blocked — page must be served over HTTPS.
How to flash firmware:
1. Plug the device into this computer via USB.
2. Click Flash Firmware via USB above.
3. Pick the port named like usbmodem… or USB JTAG/serial.
4. Wait for it to finish — device reboots automatically.
Chrome or Edge on desktop only. Web USB isn't supported in Safari, Firefox, or on phones. Wi-Fi credentials are preserved (no full erase).

SD Card

Writes the required game & speedometer files to your SD card: speedometer GIFs, splash screen, NES/SMS ROMs, boot image assets. Your photos and custom files are not touched.
💾 —
How to flash SD card:
1. Insert the SD card into a card reader on this computer.
2. Click Select SD Card & Flash.
3. In the system dialog, select the SD card's root folder.
4. The browser writes the files directly — no install needed.
Chrome or Edge on desktop only. Firefox and Safari don't support the File System Access API used to write files to the card.
✓ Safe to run on a card that already has photos. Only game & speedometer assets are written — nothing is deleted.
