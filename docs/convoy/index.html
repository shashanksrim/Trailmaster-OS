TRAILMASTER CONVOY

Setup needed

This app needs a free Firebase project to relay convoy positions.

  1. Open docs/convoy/config.js.
  2. Create a project at console.firebase.google.com, add a Realtime Database + a Web app.
  3. Paste the firebaseConfig values into that file and reload.

Full steps + the security rules to paste are in docs/convoy/README.md.
